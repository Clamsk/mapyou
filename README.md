# MapYou | 福州社区便利度交互地图

课程团队项目的**私有源码审阅版**。基于社区点、服务设施与路网，通过网页调整设施偏好并展示社区便利度。此版本不是生产系统，也不是经过独立验证的出行导航或规划工具。

## 研究与产品思路

将生活圈评价中的个体差异与设施需求转化为交互参数，连接数据采集、空间分析与地图展示。原项目覆盖福州六个市辖区，组织餐饮、超市、医疗、教育、交通、休闲、公园、金融八类设施。

## 本次归档内容

- `app.py`：原始 `交互式便利度地图_服务器.py`，仅更名，算法未修改。
- `templates/interactive_map.html`：原始网页模板，保持不变。
- `requirements.txt`：从原项目提取的运行依赖版本，兼容性仍需验证。
- `docs/REVIEW.md`：源码核对发现、运行边界与待办。

目前是**核心交互模块**归档，不代表完整课程材料或全部采集、分析脚本已上传。未纳入原始POI、调查数据、GIS数据库、缓存、EXE、压缩包和论文附件。

## 技术栈与实际实现

Python、Flask、Pandas、NumPy、NetworkX、SciPy KDTree、Folium、HTML/CSS/JavaScript。

服务器将社区和设施关联到路网节点，通过按边长加权的Dijkstra搜索统计不同类别设施；输出类别多样性、综合分值及归一化分值，用聚合标记和热力图展示。当前实现用偏好权重的倒数调整搜索半径，并不是标准的加权求和模型。

**重要：腿长尚未实际约束当前服务器版的设施统计；权重为0也未排除该类别。详见审阅记录。请勿将原说明中的“精确可达性”“腿长已影响结果”等表述作为已验证结论。**

## 本地运行条件

建议单独准备Python 3.11虚拟环境（依赖组合尚未完整安装测试）：

```sh
python -m venv .venv
# 激活虚拟环境后
python -m pip install -r requirements.txt
python app.py
```

需要自行提供有使用权限的本地文件，置于项目根目录的 `输出/`：

1. `缓存_路网图.gpickle`：NetworkX路网；节点包含x/y坐标，边包含length。
2. `缓存_总社区poi.xlsx`：name、lat、lng，可选region。
3. `缓存_总设施poi.xlsx`：category、lat、lng；或提供 `缓存_总设施poi_带节点.xlsx`，另含node。

这些文件不在仓库中，因此**下载仓库后不能直接完成真实数据计算**。缺数据时原程序会退出。只加载自己生成且可信的pickle文件；pickle反序列化可执行代码。

程序仅监听 `127.0.0.1:5000`，不要直接部署到公网。浏览器加载底图及Folium前端资源需要网络；地图服务和数据使用应遵守各提供方条款。
