# 运行与数据说明

## 推荐入口

先运行 `python demo.py`。它在内存中生成合成数据，不读取课程缓存，不调用采集接口。真实数据入口为 `python app.py`。

## 真实数据服务器

在仓库根目录建立 `输出/`，放入有使用权限且可信的数据：

| 文件 | 要求 |
| --- | --- |
| 缓存_路网图.gpickle | NetworkX图，节点含x经度、y纬度，边含length米 |
| 缓存_总社区poi.xlsx | name、lat、lng，建议含region |
| 缓存_总设施poi.xlsx | name、category、lat、lng |
| 缓存_总设施poi_带节点.xlsx | 可选设施缓存，另含与图一致的node；存在时优先读取 |

八类名称：餐饮设施、超市商场、医疗设施、教育设施、交通设施、休闲娱乐设施、公园广场、金融设施。历史脚本的类别口径可能不同，应先统一再重算。缓存须匹配图和依赖版本，禁止加载陌生来源的pickle。

## 离线分析

1. 准备 `社区poi/`、`设施poi/` 下的Excel，以及 `OSM福建/gis_osm_roads_free_1.shp` 的完整配套文件。
2. 检查坐标系、缺失值、名称和重复点；原脚本提供中文字段重命名逻辑。
3. 执行 `python 设施可达性分析_弗劳德数.py` 生成腿长情景统计与缓存。
4. 执行 `python 设施便利度_空间聚类分析.py` 进行后续图表与聚类分析。

`设施可达性分析.py` 为按类别阈值的路网版本，`设施可达性分析_直线距离.py` 为对照版本。不要混用不同定义的结果，也不要并发运行写同一缓存的脚本。

可用环境变量 MAPYOU_DATA_DIR 指定离线数据根目录；app.py仍读取项目根目录的输出文件夹。

## 采集工具

正式API脚本 `get_fuzhou_poi.py` 和 `get_gulou_poi_test.py` 从 BAIDU_MAP_AK 读取Key。后者可设置 MAPYOU_BOUNDARY。空Key不可采集；环境变量须在shell设置，.env.example不自动载入。

`poi_crawler_gui.py`、旧2.0版本和 `baidu_poi_crawler.py` 是历史网页采集实现，仅静态归档。不得把源码理解为服务授权或批量调用许可。未执行外部采集，也未验证接口现状。

`convert_bd09_to_wgs84.py` 提供历史坐标转换，近似精度需自行核验。

## 历史与打包入口

`交互式便利度地图_服务器.py` 为原命名服务器，与app.py算法相同，仅格式整理。快速版留作比较，不是推荐演示入口。

`build_exe.py`、MapYou.spec及PowerShell打包文件保留历史流程，未重新打包。部分脚本会清理build/dist目录，只能在独立项目副本中审阅后运行，不可在其他工作目录运行。EXE不随仓库分发。
