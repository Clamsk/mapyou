# 百度地图POI爬虫 v1.0

一款基于百度地图的POI（兴趣点）数据爬取工具，支持自定义区域边界、多类别关键词爬取、断点续爬等功能。

## 功能特性

- 🗺️ **自定义区域**：支持上传GeoJSON格式的边界文件，精确限定爬取范围
- 📂 **8大POI类别**：餐饮设施、超市商场、医疗设施、教育设施、公园广场、交通设施、金融设施、休闲娱乐设施
- ✏️ **关键词可编辑**：每个类别的搜索关键词均可自定义修改
- ⏸️ **暂停/继续**：支持随时暂停和继续爬取
- 💾 **进度保存**：支持保存当前进度，下次可从断点继续
- 📊 **双格式导出**：同时导出Excel(.xlsx)和CSV格式，方便后续处理
- 🌐 **坐标转换**：自动将百度坐标(BD-09)转换为GPS坐标(WGS-84)，便于在ArcGIS等GIS软件中使用

## 系统要求

- Windows 10/11 操作系统
- 无需安装Python环境（已打包为独立exe）

## 使用方法

### 1. 启动程序

双击 `百度地图POI爬虫.exe` 启动程序。

### 2. 设置爬取区域

1. 点击 **「选择GeoJSON」** 按钮，选择区域边界文件
2. 在 **「搜索区域名称」** 输入框中确认或修改区域名称（如：福州市鼓楼区、北京市海淀区）
3. 点击 **「输出目录」** 选择数据保存位置（默认为桌面）

### 3. 选择POI类别

- 勾选需要爬取的POI类别
- 点击类别旁的 **「编辑」** 按钮可自定义该类别的搜索关键词

### 4. 开始爬取

1. 点击 **「开始爬取」** 按钮开始爬取
2. 爬取过程中可点击 **「暂停」** 暂停爬取
3. 暂停后可点击 **「继续」** 继续爬取，或点击 **「停止」** 终止爬取

### 5. 保存与导出

- **保存进度**：点击 **「保存进度」** 可将当前爬取进度保存为JSON文件
- **加载进度**：点击 **「加载进度」** 可从之前保存的进度文件继续爬取
- **导出数据**：爬取完成后点击 **「导出数据」** 保存结果

## 输出数据说明

导出的数据包含以下字段：

| 字段名     | 说明                              |
| ---------- | --------------------------------- |
| 类别       | POI所属类别（如：餐饮设施）       |
| 名称       | POI名称                           |
| 地址       | POI地址                           |
| 经度_BD09  | 百度坐标系经度                    |
| 纬度_BD09  | 百度坐标系纬度                    |
| 经度_WGS84 | GPS坐标系经度（可直接用于ArcGIS） |
| 纬度_WGS84 | GPS坐标系纬度（可直接用于ArcGIS） |
| 电话       | 联系电话                          |
| 详细信息   | POI标签/分类信息                  |
| uid        | 百度地图唯一标识                  |

## GeoJSON边界文件

程序需要GeoJSON格式的边界文件来限定爬取范围。可以从以下途径获取：

1. **阿里云DataV**：https://datav.aliyun.com/portal/school/atlas/area_selector
2. **GADM**：https://gadm.org/
3. **天地图**：https://www.tianditu.gov.cn/
4. **自行绘制**：使用QGIS、ArcGIS等GIS软件绘制

## 常见问题

**Q: 为什么爬取到的POI数量较少？**

A: 可能原因：

- 搜索区域名称不够精确，建议使用"XX市XX区"格式
- 关键词覆盖不全，可以编辑添加更多关键词
- 该区域确实POI较少

**Q: 程序闪退怎么办？**

A: 请尝试：

- 以管理员身份运行
- 检查GeoJSON文件格式是否正确
- 确保输出目录有写入权限

**Q: 如何在ArcGIS中使用导出的数据？**

A:

1. 打开ArcGIS Pro
2. 添加Excel或CSV文件
3. 右键 → Display XY Data
4. X Field选择"经度_WGS84"，Y Field选择"纬度_WGS84"
5. 坐标系选择WGS 1984
