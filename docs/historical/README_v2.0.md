## 🚀 快速开始

### 1. 运行程序

双击 `百度地图POI爬虫v2.0.exe` 启动程序。

### 2. 设置区域

- 点击 **「选择边界文件」** 加载GeoJSON或Shapefile边界
- 在 **「搜索区域名称」** 输入框中填写搜索区域（如：福州市仓山区）
- 程序会自动识别对应的城市代码

### 3. 选择POI类别

- 勾选需要爬取的POI类别
- 点击 **「编辑」** 可修改每个类别的搜索关键词
- 点击 **「+ 新增类别」** 可添加自定义类别
- 点击 **「- 删除类别」** 可删除选中的类别

### 4. 开始爬取

- 点击 **「▶ 开始爬取」** 开始采集数据
- 运行过程中可以 **暂停/继续/停止**
- 进度会实时显示在日志区域

### 5. 导出数据

- 爬取完成后自动保存Excel文件
- 也可点击 **「📤 导出数据」** 手动导出
- 支持格式：Excel (.xlsx)、CSV、JSON

## 📁 边界文件说明

### 支持的格式

| 格式      | 扩展名          | 说明                   |
| --------- | --------------- | ---------------------- |
| GeoJSON   | .geojson, .json | 推荐格式，支持多种编码 |
| Shapefile | .shp            | 需要同目录下有.dbf文件 |

### 获取边界文件

1. **阿里云DataV**: https://datav.aliyun.com/portal/school/atlas/area_selector
2. **GADM**: https://gadm.org/download_country.html
3. **OpenStreetMap**: 使用Overpass API导出

### 坐标系说明

- 边界文件应使用 **WGS-84** 坐标系（标准GPS坐标）
- 程序会自动进行坐标转换

## 💡 使用技巧

### 提高采集效率

1. **精确关键词**: 关键词越具体，结果越精准
2. **合理延迟**: 建议设置2-4秒延迟，避免被封IP
3. **分批爬取**: 大区域建议分区县分批爬取

### 断点续爬

1. 爬取过程中可随时点击 **「💾 保存进度」**
2. 下次启动后点击 **「📂 加载进度」** 继续爬取
3. 已采集的数据不会重复

### 使用代理

1. 勾选 **「启用代理」**
2. 输入代理地址，格式：
   - HTTP代理: `http://ip:port`
   - SOCKS5代理: `socks5://ip:port`
