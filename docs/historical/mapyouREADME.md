# MapYou - 福州社区便利度分析系统

## 📋 项目简介

MapYou是一个交互式社区便利度分析工具，基于步行可达性理论，为福州市2977个社区提供个性化的便利度评估。用户可以根据自己的步长和对不同设施的需求偏好，生成专属的便利度地图。

## ✨ 功能特点

### 🎯 个性化分析
- **自定义步长**：支持0.5-1.2米步长调节，适应不同年龄和身体状况
- **权重调节**：8类设施独立权重设置（0-3级），反映个人需求偏好
- **实时计算**：基于路网最短路径的精确可达性分析

### 📊 三维评估体系
- **多样性指数**：评估社区周边设施类型的丰富程度
- **综合可达性**：综合考虑距离、权重和设施数量的总体便利度
- **总可达设施数**：统计可达范围内的设施总量

### 🗺️ 交互式可视化
- **热力地图**：直观展示便利度空间分布
- **可折叠面板**：简洁的用户界面设计
- **预设模式**：均衡、生活、健康、教育四种快捷模式

## 🎮 操作指南

### 参数设置

#### 步长设置（0.5-1.2米）
- **0.5-0.6米**：老年人、行动不便者
- **0.7-0.8米**：普通成年人慢速步行
- **0.9-1.0米**：正常步行速度
- **1.1-1.2米**：快速步行、年轻人

#### 设施权重（0-3级）
- **权重0**：不关注此类设施，不纳入计算
- **权重1**：一般需求（搜索半径 = 基础半径）
- **权重2**：重要需求（搜索半径 = 基础半径 ÷ 2）
- **权重3**：核心需求（搜索半径 = 基础半径 ÷ 3）

> 💡 **权重原理**：权重越高，对该设施的距离要求越严格

#### 设施类型（8类）
| 设施类型 | 包含设施 | 数量 |
|---------|---------|------|
| 餐饮设施 | 餐厅、小吃店、饮品店 | 6,092 |
| 超市商场 | 超市、便利店、商场 | 2,518 |
| 医疗设施 | 医院、诊所、药店 | 1,439 |
| 教育设施 | 学校、幼儿园、培训机构 | 1,426 |
| 交通设施 | 公交站、地铁站 | 1,598 |
| 休闲娱乐 | 电影院、KTV、游乐场 | 1,242 |
| 公园广场 | 公园、广场、绿地 | 995 |
| 金融设施 | 银行、ATM | 880 |

### 预设模式

#### 🎯 均衡模式
所有设施权重均为1，全面评估社区综合便利度

#### 🏠 生活模式
侧重日常生活设施：
- 超市商场（权重3）
- 餐饮设施（权重2）
- 交通设施（权重2）

#### 💪 健康模式
关注健康相关设施：
- 医疗设施（权重3）
- 公园广场（权重2）
- 休闲娱乐（权重1）

#### 📚 教育模式
强调教育环境：
- 教育设施（权重3）
- 公园广场（权重2）

## 🔧 技术说明

### 核心算法
- **步行速度模型**：基于Froude数理论的步行速度计算
- **路网分析**：基于589,041节点路网的Dijkstra最短路径
- **可达性计算**：双衰减函数（高斯距离衰减 + 权重距离阈值）

### 计算性能
- **首次计算**：约100分钟（全部2977个社区）
- **缓存加速**：后续计算即时响应
- **数据预加载**：启动时自动加载缓存数据

### 技术栈
- **后端**：Flask 3.1.2 (Python)
- **数据处理**：Pandas, GeoPandas, NetworkX
- **路径计算**：Scipy, NetworkX Dijkstra
- **可视化**：Folium, Branca
- **打包工具**：PyInstaller 6.3.0

## 📊 评估指标详解

### 多样性指数（Diversity）
计算公式：通过可达的设施类型数量 ÷ 8

- 0.0 = 无可达设施
- 0.5 = 可达4类设施
- 1.0 = 全部8类设施均可达

### 综合可达性（Comprehensive）
综合考虑：
- 各类设施的数量
- 距离衰减（高斯函数）
- 权重影响（需求强度）

值越高表示综合便利度越好

### 总可达设施数（Total）
统计在搜索半径内可达的所有设施数量
