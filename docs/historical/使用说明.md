## 🚀 使用方法

### 方式一：本地使用
1. 双击运行 `MapYou-福州社区便利度分析.exe`
2. 等待3-5秒，程序会自动在浏览器中打开
3. 如果浏览器未自动打开，手动访问: http://127.0.0.1:5000
4. 在网页中设置参数并生成地图

2. 用户直接双击运行即可（无需安装任何环境）

## 📋 功能说明

### 参数设置
- **腿长** (0.5-1.2米): 影响步行速度和15分钟可达距离
- **设施权重** (0-3倍): 权重越高，要求设施越近
  - 权重公式: `搜索半径 = 基础半径 / 权重`
  - 例如：医疗权重2.0，基础1500m → 实际搜索750m

### 8类设施
- 餐饮 (基础800m)
- 超市 (基础800m)
- 医疗 (基础1500m)
- 教育 (基础1500m)
- 交通 (基础1000m)
- 休闲 (基础1500m)
- 公园 (基础1500m)
- 金融 (基础800m)

### 三大指标
1. **多样性 (0-8)**: 可达设施的类别数量
2. **综合便利度**: 多样性×100 + log10(总设施数+1)×10
3. **总便利度 (0-8)**: 归一化后求和

## 🔧 技术信息

### 数据规模
- 社区: 2977 个
- 设施: 16190 个
- 路网节点: 589041 个
- 缓存数据: 已预计算节点分配

### 计算性能
- 首次启动: 3-5秒（加载缓存）
- 单次计算: 约100分钟（2977个社区）
- 进度显示: 每10个社区更新一次

### 技术栈
- 后端: Flask 3.1.2
- 数据: Pandas, NetworkX, GeoPandas
- 地图: Folium + Leaflet.js
- 打包: PyInstaller 6.3.0

## ❓ 常见问题

**Q: 双击exe没反应？**
A: 检查杀毒软件是否拦截，添加到白名单

**Q: 浏览器未自动打开？**
A: 手动访问 http://127.0.0.1:5000

**Q: 计算很慢？**
A: 正常，2977个社区需约100分钟，可查看控制台进度

**Q: 如何关闭程序？**
A: 关闭黑色控制台窗口即可

**Q: 可以在其他城市使用吗？**
A: 需要替换数据文件（社区POI、设施POI、路网图）
