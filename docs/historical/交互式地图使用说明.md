# 🎯 交互式便利度地图使用说明

## 功能介绍

这是一个Web应用程序，允许用户自定义参数并实时生成个性化的社区便利度地图。

### 主要功能

1. **自定义腿长**：输入您的腿长（0.5-1.2米），系统会根据弗劳德数公式计算您的15分钟步行距离
2. **调整设施权重**：为8类设施（餐饮、超市、医疗、教育、交通、体育、公园、便民）设置不同权重（0-3）
3. **实时计算**：点击按钮后实时计算并生成专属地图
4. **交互地图**：支持缩放、图层切换、点击查看详情等功能

## 使用步骤

### 1. 启动服务器

```bash
# 确保虚拟环境已激活
.venv\Scripts\activate

# 运行服务器
python 交互式便利度地图_服务器.py
```

服务器启动后，会显示：
```
服务器准备就绪！
请在浏览器中打开: http://127.0.0.1:5000
```

### 2. 打开浏览器

在浏览器中访问：`http://127.0.0.1:5000`

### 3. 设置参数

#### 腿长设置
- 手动输入：在输入框中输入精确值（如 0.85）
- 快捷选择：点击预设按钮
  - 儿童 (0.70m)
  - 成人 (0.85m) - 默认值
  - 高个 (1.00m)
  - 特高 (1.15m)

#### 设施权重
- 拖动滑块调整每类设施的权重（0-3）
- 使用预设方案：
  - **均衡模式**：所有设施权重为1.0
  - **生活优先**：超市、便民、交通权重高
  - **健康优先**：医疗、体育、公园权重高
  - **教育优先**：教育、交通权重高

### 4. 生成地图

点击 **"🚀 生成专属地图"** 按钮，系统会：
1. 计算所有社区的便利度（约1-2分钟）
2. 生成交互式地图
3. 在右侧显示结果

### 5. 查看结果

地图包含：
- **社区标记**：按便利度等级分为高/中/低三个图层
- **热力图**：展示加权便利度的空间分布
- **详细信息**：点击任意社区查看具体指标
- **统计汇总**：地图顶部显示总体统计

## 权重说明

权重影响便利度计算：

- **0**：完全忽略该类设施
- **1.0**：标准权重（默认）
- **2.0**：重要性翻倍
- **3.0**：非常重要

**示例场景**：
- 有小孩的家庭：教育权重设为3.0
- 老年人：医疗权重设为3.0，体育和公园设为2.0
- 上班族：交通权重设为3.0，餐饮和便民设为2.0

## 技术细节

### 计算公式

1. **步行速度**（弗劳德数）
   ```
   FS = √(腿长 × 9.8)
   TPWS = 0.42 × FS
   15分钟距离 = TPWS × 900秒
   ```

2. **加权便利度**
   ```
   加权便利度 = Σ(设施有无 × 权重) / Σ(权重) × 8
   ```

3. **便利度等级**
   - 高便利度：≥ 7分
   - 中等便利度：4-6分
   - 低便利度：< 4分

### 数据要求

服务器需要以下缓存文件（由主分析脚本生成）：
- `缓存_路网图.gpickle`：路网图数据
- `缓存_总社区poi.xlsx`：社区数据
- `缓存_总设施poi.xlsx`：设施数据

如果缺少这些文件，请先运行 `设施可达性分析.py` 生成缓存。

## 性能优化

- 首次计算：1-2分钟（需遍历所有社区）
- 数据预加载：启动时自动加载路网和POI数据
- KD树索引：加速最近节点查找

## 故障排除

### 服务器无法启动
- 检查是否安装了Flask：`pip list | findstr Flask`
- 检查缓存文件是否存在
- 查看终端错误信息

### 计算失败
- 确认输入的腿长在有效范围内（0.5-1.2）
- 检查权重是否正确设置
- 查看浏览器控制台和服务器日志

### 地图不显示
- 刷新浏览器页面
- 检查网络连接
- 确认计算已完成（无加载提示）

## 注意事项

1. **计算时间**：首次计算需要1-2分钟，请耐心等待
2. **浏览器兼容性**：推荐使用Chrome、Edge、Firefox等现代浏览器
3. **数据更新**：如需更新POI或路网数据，重新运行主分析脚本生成缓存
4. **服务器资源**：计算过程会占用一定CPU和内存，建议关闭其他占用资源的程序
