# MapYou - 福州市社区便利度个性化分析系统
## 使用手册

### 📦 软件打包说明

本软件已打包成独立的Windows可执行文件，用户无需安装Python等环境即可使用。

---

### 🚀 快速开始

#### 方式一：直接运行（开发环境）
如果你有Python环境：
```powershell
python 交互式便利度地图_服务器.py
```

#### 方式二：打包成软件（分发给他人）

1. **运行打包脚本**
   - 右键点击 `打包.ps1`
   - 选择"使用PowerShell运行"
   - 等待5-10分钟完成打包

2. **分发软件**
   - 打包完成后，在 `dist` 文件夹中找到 `MapYou-福州社区便利度分析.exe`
   - 文件大小约 500MB - 1GB（包含所有数据和依赖）
   - 将此exe文件发送给用户

3. **用户使用**
   - 双击 `MapYou-福州社区便利度分析.exe`
   - 等待几秒钟，浏览器会自动打开
   - 在网页中设置参数并生成地图

---

### 📋 系统要求

- **操作系统**: Windows 10/11 (64位)
- **内存**: 至少 4GB RAM
- **磁盘空间**: 至少 2GB 可用空间
- **浏览器**: Chrome/Edge/Firefox 最新版

---

### ⚙️ 功能特性

1. **个性化参数设置**
   - 腿长设置（0.5-1.2米）
   - 8类设施权重调节（0-3倍）
   - 预设模式：均衡/生活/健康/教育

2. **三大便利度指标**
   - 多样性：有设施的类别数（0-8）
   - 综合便利度：多样性×100 + log10×10
   - 总便利度：归一化后求和（0-8）

3. **可视化展示**
   - 三个独立热力图图层
   - 社区标记分级显示
   - 详细信息弹窗
