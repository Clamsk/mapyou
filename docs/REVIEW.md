## 重要发现（保持原始算法，待确认后修复）

1. `calculate_accessibility`接收leg_length但未使用；Dijkstra截断及分类半径来自radii/weight。`calculate_walking_distance`计算的距离仅用于地图标题等显示。需要确定腿长应如何与各类设施半径共同约束，不能擅自选公式。
2. 权重为0被替换为0.1作为分母，反而扩大搜索范围，不是排除该设施类别。
3. KDTree直接使用经纬度欧氏距离，米制转换采用统一111000系数，未考虑经度随纬度变化；社区/设施吸附路网的连接距离也未计入最短路径。
4. 综合分值是类别数×100 + log10(设施总数+1)×10；总便利度按当前社区样本内各类别最大值归一化求和。其尺度依赖样本，不宜直接作为跨样本绝对指标比较。
5. 原README中的“步长”应为腿长；“双衰减函数”等叙述不符合此服务器版本的实际计数实现，不在新README沿用。
6. 目前缺少服务端参数范围/有限值校验、可靠的数据就绪检查、完整异常分类；未经转义的名称进入地图HTML。仅用于可信本地数据审阅，勿公网部署。
7. pickle缓存只能从可信来源加载。第三方POI及路网的授权、坐标与精度需单独核查。
